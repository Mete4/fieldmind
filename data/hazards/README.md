# Hazard layers (real data) for the Paradise, California scenario

Everything in this folder except `raw/` is generated by
`scripts/prepare_data.py` (run once, online). Each layer is reprojected to
EPSG:4326, clipped to the bounding box in `app/config.py`
(-121.72, 39.69, -121.52, 39.83), simplified (~3 m tolerance) and written as
`<id>.geojson` with two normalized properties: `zone` (machine code, see
`ZONE_STYLES` in `app/config.py`) and `label`. `layers.json` is the manifest
that `app/hazards.py`, the API and the dashboard read.

The incidents are **simulated**. The geography and every hazard layer below
are **real, official datasets**.

## Layers

| id | What | Source / download | License / attribution |
|---|---|---|---|
| `fire` | Fire Hazard Severity Zones: Very High / High / Moderate, State Responsibility Area (SRA, 2022-23) and Local Responsibility Area (LRA, 2024-25) combined. Counts for `in_hazard_zone`. | CAL FIRE / Office of the State Fire Marshal. Maps and GIS downloads: <https://osfm.fire.ca.gov/what-we-do/community-wildfire-preparedness-and-mitigation/fire-hazard-severity-zones> ; FRAP GIS data: <https://www.fire.ca.gov/what-we-do/fire-resource-assessment-program/gis-mapping-and-data-analytics>. REST layer used: CAL FIRE's hosted `fhsz24_1/FeatureServer/0` (fields SRA, FHSZ_Description, FHSZ_6Class), the combined SRA + LRA map. | Public data from the State of California. Attribution: "CAL FIRE Fire Hazard Severity Zones". |
| `flood` | FEMA flood hazard zones (S_FLD_HAZ_AR): 1 %-annual-chance Special Flood Hazard Area (Zone A/AE, `flood_100yr`) and 0.2 %-annual-chance zone (`flood_500yr`). Counts for `in_hazard_zone`. | FEMA National Flood Hazard Layer: <https://www.fema.gov/flood-maps/national-flood-hazard-layer> ; REST: `hazards.fema.gov/arcgis/rest/services/public/NFHL/MapServer/28` | US Government work, public domain. |
| `camp_fire` | Final perimeter of the 2018 Camp Fire (153,336 acres). Display-only context. | CAL FIRE FRAP California Fire Perimeters: <https://www.fire.ca.gov/what-we-do/fire-resource-assessment-program/fire-perimeters> ; REST: CAL FIRE hosted `2018_California_Fire_Perimeters_View/FeatureServer/0` | Public data from the State of California. Attribution: "CAL FIRE FRAP". |
| `firms` (optional) | NASA FIRMS VIIRS active-fire detections, last 3 days, as points. Display-only. | <https://firms.modaps.eosdis.nasa.gov/api/area/> (needs a free MAP_KEY in env `FIRMS_MAP_KEY`) | NASA open data; cite "NASA FIRMS". |
| `quakes` (optional) | Recent earthquakes within about 50 km, last 90 days, M >= 1.0 (live at prep time, not clipped to the town box). Display-only. | USGS FDSN event service: <https://earthquake.usgs.gov/fdsnws/event/1/> | US Government work, public domain. |

Base map: OpenStreetMap raster tiles cached locally for z10-16
(`data/tiles/`), (c) OpenStreetMap contributors, ODbL. Place names
(`data/gazetteer.json`) come from OpenStreetMap via the Overpass API, same
license. Tiles were fetched once, with 2 threads and a descriptive User-Agent,
following the OSM tile usage policy; they are never fetched at run time.

## Manual download (if a REST download fails or you want another layer)

Put the file into `data/hazards/raw/` with the layer id as file name, e.g.
`raw/fire.zip` (zipped shapefile from the CAL FIRE FHSZ page),
`raw/flood.zip` (FEMA NFHL county download, Butte County 06007C, keep only
S_FLD_HAZ_AR), `raw/firms.csv` (FIRMS archive download), `raw/camp_fire.kml`.
Files whose names contain `fhsz`/`fire`, `flood`/`nfhl`/`fld`, `firms`,
`perimeter`/`camp` or `quake` are recognised too. Then run:

    .venv/bin/python scripts/prepare_data.py --only hazards

Missing layers are skipped with a log line; the app runs without them.

## How zones are used

`app/hazards.py` loads every polygon layer with `"pip": true` in
`layers.json` into a shapely STRtree. For each incident it records
`hazard_zones` (e.g. `["fire_very_high", "flood_100yr"]`), `in_hazard_zone`
and adds the hazard bonus to `priority_score`. Point layers and the Camp Fire
perimeter are display-only.
